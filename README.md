## Project Overview
A comprehensive database system for a car rental agency built using PostgreSQL. The system manages car fleets, categories, customers, staff, rental contracts, and payments.

## Features
- 6 Related Tables with Primary and Foreign Keys.
- 17 Complex SQL Queries (Joins, Subqueries, Group By).
- Full ER Diagram for database schema visualization.

## Technologies Used
- **Database:** Supabase (PostgreSQL)
